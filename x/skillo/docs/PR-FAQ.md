# Press Release & FAQ

## Press Release

**skillo: Go Modules Meet Agent Skills – Install Skills Like Dependencies**

*Arcadia, 2026* – Introducing **skillo**, the Go CLI that treats agent skills as first-class Go modules. No more npm/curl fragility.

Developers struggle with skill installs across agents. skillo solves this with `go get`-powered versioning for any Git repo.

\"Finally, skills get proper dependency management,\" says B. Locera.

\"Transformative for agent workflows,\" raves early user.

[Install now](https://github.com/bolocera/arcadia/tree/main/x/skillo).
