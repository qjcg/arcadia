For AI agent developers who need their agents to remember across sessions,
Mnemosyne is a command-line tool that provides structured, typed, distributed
memory over NATS KV. Unlike rolling custom Redis or SQLite solutions,
Mnemosyne gives agents episodic, semantic, and procedural memory with
tagging, TTL-based expiration, importance scoring, and multi-tenant
isolation — all through a single CLI command and a simple Go library
interface.
