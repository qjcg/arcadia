# Agent Plugins

Generated [Agent Plugins](https://agent-plugins.org/specification) v1.0.0 packages.
Each subdirectory is a self-contained plugin root (`plugin.json` + `skills/<name>/SKILL.md`).

- **Do not edit these trees by hand.** They are generated by `task plugins:sync` from
  the sync specs in [`specs/`](specs) (`agents/skills/` for first-party skills,
  pinned upstream refs for vendored skills). Validate with `task plugins:validate`.
- Conventions, sync policy, and rationale: see the ADRs in [`docs/adrs`](../../docs/adrs).
